- React, JavaScript, Vite y Tailwind CSS; Node.js y Express; PostgreSQL real. Monolito modular de tres capas.
- Flujo: React → cliente HTTP → rutas → controladores → servicios → repositorios → PostgreSQL. SQL parametrizado solamente en persistencia y migraciones.
